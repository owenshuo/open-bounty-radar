## Unreleased

## 0.3.0

- Add a scheduled GitHub Pages live discovery dashboard.
- Publish hosted live and offline demo dashboard entry points.
- Refresh the scan dashboard with a darker live-radar UI.
- Improve local proxy stability by using Undici ProxyAgent.
- Add a faster broad-discovery mode with optional linked PR detection disabled.
- Add request timeout and proxy configuration documentation.
- Add payment-risk, crowded-proposal, and bounty-date false-positive handling improvements.

## 0.2.0

- Add action-oriented scan grouping and dashboard reports.
- Add interactive scan dashboard filters, search, and copyable issue URLs.
- Add watch next-action hints, winner/payment signals, and watch dashboard output.
- Add GitHub search presets.
- Add Algora and Opire adapter foundations for GitHub-linked listing sources.
- Add CSV, JSONL, and action-plan exports.
- Add JSONL history append support.
- Add GitHub Actions workflow template.
- Add config schema and adapter examples.
